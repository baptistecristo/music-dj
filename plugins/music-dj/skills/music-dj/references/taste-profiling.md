# Taste profiling — scan, learn, store

The DJ's brain is `~/.music-dj/taste-profile.md`, generated by scanning the
user's library on the chosen service. It stays on the user's machine.

## What to collect (per service capability)

- Library artists (as many as reasonably paginated — a few hundred)
- Genre distribution over library songs
- Recently played tracks
- Favorites / likes / heavy rotation where the service exposes them

Service-specific scan snippets live in each service reference
(`apple-music.md` has fully tested MusicKit calls; the others describe the
page/API surface to use). Pull data in compact chunks — tool outputs
truncate around 1,500 characters, so slice arrays and aggregate in-page.

## Writing the profile

Write `~/.music-dj/taste-profile.md` with exactly these sections (this is
the template — replace bracketed text with findings):

```markdown
# Taste profile — [name]

Built [date] from a scan of [service]: [N] artists, genre counts, recent
plays. Refresh by asking the DJ to "refresh my taste profile".

## The shape of the library

- [Genre/scene shelf 1 — biggest first, with representative artists]
- [Shelf 2 ...]
- [Recent listening tendencies]
- Summary line: [overall character — languages, eras, energy, what's absent]

## Mood → seed directions

Pick ONE seed song per switch (vary seeds; never the same twice in a row):

- **energized / shipping something** → [artists/songs]
- **tense / debugging / frustrated** → [calm warm picks]
- **locked in / deep focus** → [instrumental-leaning picks]
- **mellow / writing / reflective** → [soft picks]
- **loose / late night / celebrating** → [feel-good picks]

## Don'ts

- [Genres/moods to avoid, and when]
- Don't over-play the user's recent-plays list — discovery within taste,
  not a mirror.
```

## Rules

- Never publish or upload the profile anywhere; it is personal data.
- If the profile is missing at DJ time, offer to run the scan (or DJ from
  the user's stated preferences for now).
- When the user corrects the DJ ("less rap when I'm focused"), edit the
  profile immediately so the correction sticks.
